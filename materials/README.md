# Materials

No PyKale example currently maps to this domain. The bucket exists so that materials work has an
obvious home when it arrives, rather than being filed under `others` and later moved — a move that
would break every link to it.

Earmarked for:

- structure/property prediction
- crystal and material descriptors
- materials benchmark tasks

If you are adding the first tutorial here, see [CONTRIBUTING.md](../CONTRIBUTING.md) and add the
slug to the `materials` bucket in [`tutorial_catalog.yml`](../tutorial_catalog.yml).
