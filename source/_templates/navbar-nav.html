{#- Custom primary navigation for PyKale Tutorials. Overrides pydata-sphinx-theme's navbar-nav component to provide named dropdowns (Learn, Domains, Ecosystem, More) instead of a flat list of top-level pages. The Domains menu is data-driven from the catalogue (passed in as `pky_nav.domains` via conf.py's html-page-context hook), so adding a domain needs no template edit. Markup is Bootstrap 5 (bundled with the theme); dropdowns are keyboard-accessible via the theme's bundled JS. -#}
